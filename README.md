# Digilapak

Landing page marketplace produk digital (e-book, template, source code, UI kit, dan preset) dibuat dengan React, Vite, dan Tailwind CSS.

## Menjalankan project

```bash
npm install
npm run dev
```

Build untuk production:

```bash
npm run build
```

## Struktur

- `src/components/` berisi komponen UI (Header, Hero, ItemSection, FeaturedProduct, Footer).
- `src/data/marketplace.js` berisi semua teks dan data produk. Ubah isi produk di sini.
- `public/assets/` berisi gambar dan ikon.
